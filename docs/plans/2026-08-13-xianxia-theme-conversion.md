# 《云荒问道》修仙主题改造定义

> 状态：P0/P1 已完成，进入视觉样板制作
> 分支：`feature/xianxia-theme-prototype`
> 日期：2026-08-13
> 原则：玩法、数值与操作保持不变，只调整世界观、显示文案、视觉资源和声音表现。

## 1. 改造目标

将当前西方奇幻像素冒险改造成“山海志怪 + 市井修仙”的中式像素冒险。

- 暂定名称：**《云荒问道》**
- 一句话设定：灵脉异动、古宗禁制松脱，一名无籍散修从栖云坊市出发，游历六境、镇压妖祟并追查白骨鬼王背后的灵潮源头。
- 玩家身份：散修，不预设救世主或天命血统。
- 叙事气质：克制、清奇、有烟火气；避免堆砌“仙帝、至尊、神王”等网文式高阶词汇。
- 视觉气质：矿物青绿、朱砂红、墨黑、玉青；建筑采用灰瓦、木构、石阶、符灯和山门元素。

## 2. 不变范围

第一阶段不新增或修改以下玩法：

- 移动、攻击、闪避、技能释放和快捷键
- 三职业战斗定位、技能效果、冷却和资源循环
- 属性公式、怪物 AI、Boss 阶段和战斗数值
- 装备栏、品质、强化、洗练、镶嵌、套装和掉落概率
- 任务、悬赏、商店、同伴、声望和对话流程
- 六类生态区、Chunk 生成、探索、传送和存档结构
- 世界尺寸、出生点、怪物密度和 Boss 坐标

## 3. 兼容性红线

下列内部标识必须保持不变，只修改玩家可见名称：

- 职业 ID：`warrior`、`archer`、`mage`
- 资源 ID：`rage`、`stamina`、`mana`
- 属性 ID：`con`、`str`、`int`、`agi`、`per`、`lck`
- 怪物、技能、物品、任务、NPC、阵营和对话节点 ID
- 生态 ID：`forest`、`ruins`、`snow`、`desert`、`swamp`、`volcano`
- 装备类型：`heavy`、`light`、`magic` 及所有 slot ID
- 品质 ID：`common` 到 `mythic`
- Phaser texture key、动画 key、事件名和存档字段

日志、测试和调试面板允许继续显示内部 ID。正式界面不得直接显示内部 ID。

## 4. 世界设定

世界暂称“云荒”。中央安全区为栖云坊市，外围六境受灵脉和地气影响形成不同生态。古宗留下的镇界禁制正在失效，妖物、尸傀和劫修开始侵入商路。

当前主线结构不增加新系统，只重写现有任务语义：

1. 玩家在栖云坊市登记散修身份并接取悬赏。
2. 清理外围精怪，取得禁制令牌和镇界古印线索。
3. 探索古宗遗址，发现阴煞灵潮来自四方封印。
4. 击败尸傀将军与白骨鬼王，暂时稳定云荒灵脉。

## 12. UI 与视觉规范

- 主界面首先显示《云荒问道》，副标题可用“像素修仙冒险”。
- 面板结构、快捷键和信息密度保持不变，只替换主题外观与术语。
- 主色使用墨黑、玉青、朱砂红，金色仅用于高品质和重要反馈。
- 边框参考木构、铜扣和回纹，不使用厚重西式铆钉板甲边框。
- 常用功能按钮继续使用清晰图标，不以生僻篆字替代通用操作。
- 替换当前界面中的 emoji 图标，正式资源使用统一像素图标集。
- 字体优先保证小字号中文可读性；标题可使用有书写感的字体，正文不使用书法字体。
- 技能特效采用剑气、符箓、阵纹、五行灵光，不持续覆盖角色和地形轮廓。

## 13. 音频方向

玩法触发点和音频生命周期保持不变，只替换音色与曲目：

- 坊市：笛、埙、轻拨弦和低密度打击乐。
- 野外：古琴泛音、风声、水声、虫鸣，保持留白。
- 战斗：鼓点、短促弦乐和金石撞击，不做持续轰鸣。
- 技能：飞剑使用破风与金属清鸣，符法使用纸符、铃音和低频灵力声。
- 稀有掉落：玉石清响，不使用西式教堂钟或管弦号角。

## 14. 原型实施范围

首个可体验版本只验证主题是否成立，范围固定为：

1. 替换游戏标题、主菜单、三职业名称与描述。
2. 替换通用 UI 术语、属性、资源、品质和装备类型显示。
3. 替换六境、九类敌人、Boss、地标、任务和主要 NPC 文案。
4. 重写三职业全部技能名称与描述，不修改技能行为。
5. 完成 57 件现有物品、材料、宝石、套装的主题命名。
6. 优先制作主角、栖云坊市、青岚竹海和四类近郊敌人的视觉样板。
7. 其余区域暂时允许复用旧像素资产，但不得将旧资产作为最终验收状态。

原型不加入境界突破、灵根、宗门、炼丹、炼器小游戏、渡劫和御剑飞行。

## 15. 实现顺序

### P0：文案与兼容层

- 增加统一的通用显示术语配置，减少 UI 中散落的硬编码文案。
- 修改各领域数据文件的 `name`、`description` 和显示标签。
- 保留全部 ID，增加旧存档显示字段刷新逻辑。
- 存档可增加 `themeVersion`，但不得要求玩家删档。

### P1：界面主题

- 主菜单、HUD、面板边框、资源图标和品质标签。
- 保持布局和交互不变，优先处理中文小字号可读性。

### P2：视觉样板

- 修士主角基础动作。
- 栖云坊市和青岚竹海 Tile/装饰。
- 浊水精、吸灵蝠、噬魂蛛、山魈。
- 三职业各 4 个常用技能特效。

### P3：全地图资源

- 其余五境、所有敌人、Boss、NPC、物品和地标资源。
- 音乐与音效主题替换。

## 16. 存档兼容方案

当前背包和装备会把名称、描述等显示字段作为快照写入存档。主题改造后仅修改 `items.json` 不足以更新旧存档，因此加载流程需要：

1. 继续使用原物品、技能、任务和 NPC ID 反序列化。
2. 根据主数据刷新物品 `name`、`description`、图标和类别标签。
3. 保留随机词条、基础属性、强化等级、宝石、套装、数量和装备位置。
4. 对无法在主数据中找到的历史物品保留原快照并记录警告，不能直接删除。
5. 任务进度按原 target ID 恢复；只在 UI 查询新的敌人显示名。
6. `themeVersion` 缺失视为旧主题存档，迁移完成后写入当前版本。

## 17. 验收标准

- 新档和旧档均可正常进入游戏，旧档装备数值与任务进度不变。
- 主菜单、HUD、角色、背包、传承、同行、任务、商店、炼器和大地图术语一致。
- 正式界面不再出现“战士、弓箭手、法师、金币、冒险者公会、哥布林、兽人、骷髅王、奥术”等旧主题词。
- 三职业技能行为、伤害、冷却和资源消耗与改造前一致。
- 所有自动化测试通过，并增加主题术语与旧存档迁移测试。
- 视觉样板在 1920x1080、1440x900 和移动窄屏下无遮挡、无文本溢出。
- 运行时帧率、Chunk 加载峰值和碰撞器数量不因主题资源退化。

- 炼气、筑基等境界突破
- 灵根与功法相性
- 宗门加入与阵营路线
- 炼丹、炼器和采集玩法
- 洞府经营与灵田
- 渡劫、御剑飞行和跨区域移动

这些系统不能仅靠改名加入，否则会让玩家对不存在的玩法产生预期。
